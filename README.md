# Karan Gupta — Portfolio

A minimal, light-only portfolio for an analyst and developer, built with HTML, CSS, and vanilla JavaScript. DM Sans and Inter Tight typography, a one-time typing introduction, scroll-driven organisation cards, sharp project tiles, accessible navigation and responsive layouts. Reduced-motion and no-JavaScript visitors get a static, readable card list.
